# 第 11 章：安全与对齐

> 核心论点：Agent 的安全风险比 chatbot 高一个数量级——因为它能行动。

## 11.1 Agent 威胁模型
比 chatbot 多了什么风险。行动能力 = 攻击面。

## 11.2 Prompt Injection 攻防
直接注入与间接注入。防御策略。

## 11.3 权限控制
最小权限原则与沙箱隔离。RBAC for Agents。

## 11.4 Agent 对齐
如何让 Agent 的目标与人类一致。Reward Hacking、Specification Gaming。

## 11.5 红队测试
系统性地发现 Agent 漏洞。攻防对抗。

## 11.6 可审计性
Agent 决策的可追溯与可解释。日志、trace、replay。
