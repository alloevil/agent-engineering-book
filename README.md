## 适合谁

- 想构建可靠 Agent 系统的工程师
- 想理解 Agent 技术原理的产品经理

- 基本的 Python/TypeScript 编程能力
- 对 LLM 有基础了解（知道什么是 prompt、API 调用）

2. 第 1-2 章末尾有思考题，建议动手实践（其余章节待补）
3. 代码示例目前仅见第 1 章正文（其余章节待补）
4. 参考论文在 `references/papers.md`
