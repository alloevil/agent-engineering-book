# 第 5 章：推理能力

> 核心论点：Agent 的推理不是"更聪明的搜索"，是从 pattern matching 到 conscious deliberation 的跃迁。

## 5.1 LLM 推理的本质
从 pattern matching 到 deliberation。System 1 vs System 2（Kahneman）。

## 5.2 Chain-of-Thought
显式推理链的设计与局限。Zero-shot CoT、Few-shot CoT。

## 5.3 结构化推理
Tree-of-Thought、Graph-of-Thought。从线性推理到树状/图状推理。

## 5.4 推理验证
如何让 Agent 知道自己推理对了。Self-verification、Process Reward Model。

## 5.5 因果推理与反事实思考
Pearl 因果层级。从相关性到因果性。

## 5.6 多 LLM 协作推理
MACI（Multi-LLM Agent Collaborative Intelligence）。熵引导信息交换。
