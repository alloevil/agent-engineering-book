| Context Engineering | Context Engineering | 设计 Agent 整个上下文环境的工程方法，2026 年替代 Prompt Engineering |
| ReAct | ReAct | Reasoning + Acting 的交替循环模式 |
| Plan-and-Execute | Plan-and-Execute | 先规划后执行的 Agent 模式 |
| Reflexion | Reflexion | 执行后自我反思的 Agent 模式 |
| MCP | Model Context Protocol | 工具生态的标准化协议 |
| Self-Evolving Agent | Self-Evolving Agent | 能从经验中自主进化的 Agent |
| RAG | Retrieval-Augmented Generation | 检索增强生成，作为上下文注入的一种形式 |
| CoT | Chain-of-Thought | 思维链推理 |
| ToT | Tree-of-Thought | 思维树推理 |
| GoT | Graph-of-Thought | 思维图推理 |
| MACI | Multi-LLM Agent Collaborative Intelligence | 多 LLM Agent 协作智能 |
| SagaLLM | SagaLLM | 事务性规划模式 |

| Red Teaming | Red Teaming | 系统性地发现 Agent 漏洞的测试方法 |
