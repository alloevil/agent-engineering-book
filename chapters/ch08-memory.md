# 第 8 章：记忆系统

> 核心论点：记忆是 Agent 从"无状态函数"到"持续存在体"的关键。

## 8.1 认知科学视角
工作记忆、情景记忆、语义记忆。人类记忆如何启发 Agent 记忆设计。

## 8.2 短期记忆
会话上下文与状态管理。上下文窗口作为工作记忆。

## 8.3 长期记忆
向量检索、图结构、文件系统。持久化策略。

## 8.4 记忆的写入、检索、衰减与遗忘
什么值得记住？如何检索？何时遗忘？

## 8.5 记忆一致性
多 Agent 共享记忆的挑战。读写冲突、版本控制。

## 8.6 Sleep-time Compute
离线记忆整理的价值。索引优化、知识提炼。
