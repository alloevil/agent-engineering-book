# 第 7 章：Context Engineering

> 核心论点：2026 年替代 Prompt Engineering 的新范式——不是写好 prompt，是设计好整个上下文环境。

## 7.1 从 Prompt Engineering 到 Context Engineering
为什么"prompt"这个词已经不够用了。上下文 = prompt + 工具输出 + 历史 + 外部信息。

## 7.2 系统提示设计
人设、规则、约束的分层架构。SOUL.md 模式。

## 7.3 动态上下文注入
何时注入什么信息。RAG 作为上下文注入的一种形式。

## 7.4 上下文窗口管理
有限资源下的信息取舍。优先级排序、相关性过滤。

## 7.5 上下文压缩与衰减
长对话的生存策略。摘要、滑动窗口、重要性加权。

## 7.6 上下文污染
外部数据中的 prompt injection 防御。数据与指令的边界。
