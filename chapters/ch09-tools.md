# 第 9 章：工具使用与环境交互

> 核心论点：工具是 Agent 行动能力的来源。没有工具的 Agent 只是一个顾问。

## 9.1 工具的本质
扩展 Agent 的行动空间。从"能说什么"到"能做什么"。

## 9.2 工具描述、注册与发现
如何让 LLM 理解工具。JSON Schema、自然语言描述。

## 9.3 工具调用模式
同步/异步/流式。长时运行工具的处理。

## 9.4 MCP 协议
Model Context Protocol：工具生态的标准化。

## 9.5 浏览器自动化
Web Agent 的架构与挑战。Playwright、Puppeteer。

## 9.6 代码执行
Agent 如何安全地编写和运行代码。沙箱、权限、审计。
