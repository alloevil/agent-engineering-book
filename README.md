## 适合谁

- 想构建可靠 Agent 系统的工程师
- 想理解 Agent 技术原理的产品经理
- 想系统学习 Agent 工程的技术管理者

## 前置知识

- 基本的 Python/TypeScript 编程能力
- 对 LLM 有基础了解（知道什么是 prompt、API 调用）

## 如何使用

1. 按章节顺序阅读，每章相对独立
2. 每章末尾有思考题，建议动手实践
3. 代码示例在 `code-examples/` 目录
4. 参考论文在 `references/papers.md`
