# 第 12 章：Agent 自进化

> 核心论点：静态模型的根本局限推动了自进化 Agent 的研究。

## 12.1 为什么 Agent 需要进化
LLM 是静态的。知识过时、能力固定、无法从经验中学习。

## 12.2 进化的维度
模型、记忆、工具、架构。What to evolve。

## 12.3 进化的时机
测试时（intra-test-time）vs 测试间（inter-test-time）。When to evolve。

## 12.4 进化的方法
标量奖励、文本反馈、自我反思、强化学习。How to evolve。

## 12.5 从自进化到自主 Agent
通往 ASI 的路径。当前研究前沿。
